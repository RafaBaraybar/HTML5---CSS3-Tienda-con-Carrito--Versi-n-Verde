# 🛍️ Tienda Online - HTML5, CSS3 y JavaScript

Proyecto de desarrollo frontend que consiste en una tienda online con catálogo de productos y carrito de compras.

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Características

- Catálogo de productos.
- Carrito de compras.
- Selección y gestión de productos.
- Cálculo del importe de compra.
- Diseño adaptable a dispositivos móviles y computadoras.
- Interfaz visual personalizada.

## 🎯 Objetivo del proyecto

Desarrollar una tienda online sencilla, intuitiva y adaptable, utilizando tecnologías frontend.
